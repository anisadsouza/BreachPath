Use your own data

Choose files and upload. Invalid files are rejected with the file and line, and your current data is kept.

Input format and limits

  • assets.csv: name,type,isolationCost[,internetFacing,patched]
  • network_edges.csv: from,to,cost,bidirectional
  • security_events.csv: hour,host,eventType,count,indicator,command ("-" = none)
  • iocs.txt: one per line, trailing * = prefix. patterns.txt: one per line, "." = any character.
  • CSVs start with a header row. Costs 0 to 1,000,000, hours 0 to 23. Max 500 assets, 2 MB.
