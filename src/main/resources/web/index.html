What if this host were the only compromised one?

Each other host is treated in turn as the only compromised host. Internet-facing, unpatched hosts come first, then the hosts that cost most to contain.

Use your own data

Choose the files, then upload. Everything is validated first; if a file is invalid, the current data stays as it was and the error names the file and line.

Input format and limits

  • assets.csv: name,type,isolationCost[,internetFacing,patched]. Costs are whole numbers from 0 to 1,000,000.
  • network_edges.csv: from,to,cost,bidirectional. Both hosts must exist in assets.
  • security_events.csv: hour,host,eventType,count,indicator,command. Hour is 0 to 23, count is 0 or more, "-" means none.
  • iocs.txt: one indicator per line; a trailing * makes it a prefix rule. patterns.txt: one pattern per line, "." is one character.
  • Each CSV starts with a header row. Lines starting with # are comments. At most 500 assets and 2 MB per upload.

Benchmarks: each technique against a baseline at three sizes

Run on the server with seeded synthetic data. Every row also checks that the technique and the baseline return the same answer. The quick run takes about 15 seconds.

All data is synthetic. Results are experiments on that data, not proof of real-world protection.
